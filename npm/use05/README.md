# use05

05 is the acceptance layer for AI-written code: agents declare their plan, 05 seals it, proves the change with deterministic checks, and gives you one page to accept or reject.

```sh
npm install -g use05
use05 init
```

This package runs the native `use05` binary for your machine (macOS and Linux, x64 and arm64), installed from one of the `@use05/cli-*` packages. Every release's binaries are also on GitHub with checksums: https://github.com/use05-dev/use05/releases

Documentation: https://github.com/use05-dev/use05
